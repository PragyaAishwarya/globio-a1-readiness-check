# German A1 Readiness Check

A simple web-based assessment tool designed to help German A1 learners evaluate their preparation before booking their Goethe or ÖSD examination.

## Project Overview

The German A1 Readiness Check provides learners with a short assessment across three fundamental skill areas:

- Vocabulary
- Grammar
- Reading

After completing 12 questions, learners receive an overall readiness score, a skill-wise performance breakdown and recommendations on areas that need further practice.

## Key Features

- 12 multiple-choice assessment questions
- Skill-wise performance tracking
- Automatic readiness score calculation
- Personalised practice recommendations
- Progress indicator during the assessment
- Option to restart and review results

## Readiness Scoring

| Score | Assessment |
|---|---|
| 80–100% | Exam-ready |
| 60–79% | Almost ready |
| Below 60% | Needs preparation |

## Technology Used

- HTML
- CSS
- JavaScript

The application is built as a lightweight, single-page web app without requiring a backend or database.

## Live Application

[Try the German A1 Readiness Check](https://luminous-gingersnap-97780e.netlify.app/)

## Limitations

This is an initial assessment prototype covering vocabulary, grammar and reading. It does not currently evaluate listening or speaking skills and is not an official Goethe or ÖSD examination predictor.

## Future Improvements

- Add listening and speaking assessments.
- Expand the question bank.
- Introduce difficulty-based questions.
- Validate readiness scores against actual learner examination outcomes.
- Provide personalised learning plans.
